System design, chai ki tapri se samjho

Reel mein 48 second the. Yahan wahi baat aaram se, plus ek 20 minute ka task jo tum aaj raat kar sakte ho.

Tapri pe kya hai, tech mein kya hai

  • Ek chaiwala, ek stove=server
  • Aur chaiwale laga do=horizontal scaling
  • Counter pe banda jo order baantta hai=load balancer
  • Thermos mein pehle se bani chai=cache
  • Hisaab ki asli copy=database
  • "Abhi nahi ho payega"=503

Chhe shabd jo ab tumhe aate hain

Server
Wo computer jo tumhari website ki har request handle karta hai. Chhote project ke liye ek hi kaafi hai.
Scaling
Load badhe toh capacity badhao. Horizontal matlab aur machines, vertical matlab ek machine ko bada karna. Pehle vertical karte hain, kyunki wo sasta aur simple hai.
Load balancer
Request aati hai, ye dekhta hai kaun sa server khaali hai, aur wahan bhej deta hai. Sabse simple tareeka round robin hai: baari baari.
Cache
Jo cheez baar baar maangi jaati hai, uska jawab paas rakh lo. Fast hai, par purana ho sakta hai, isliye expiry (TTL) rakhte hain.
Database
Data ki asli jagah. Server crash ho jaaye, data yahin safe rehta hai, isliye server aur database alag rakhte hain.
503
Server ka "service unavailable". Zyadatar iska matlab hai ki load zyada hai ya peeche kuch gir gaya.

20 minute ka task: apna pehla cache banao

  1. Ye code cache_demo.py naam se save karo aur run karo.
  2. Dekho kitne second lage.
  3. Ab loop mein fast_square ki jagah slow_square likho aur dobara run karo.
cache_demo.py 
import time

def slow_square(n):
    time.sleep(2)          # maan lo ye ek slow database call hai
    return n * n

cache = {}

def fast_square(n):
    if n in cache:
        return cache[n]    # pehle se taiyaar jawab
    cache[n] = slow_square(n)
    return cache[n]

start = time.perf_counter()
for _ in range(3):
    fast_square(7)
print(round(time.perf_counter() - start, 1), "seconds")

Kaam kiya toh: fast_square wala run lagbhag 2.0 seconds dikhayega aur slow_square wala lagbhag 6.0. Wo 4 second ka farak hi cache hai.
