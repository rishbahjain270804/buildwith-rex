Paisa kata, par pahuncha nahi

Pending matlab paisa gaya nahi. Bas jawab nahi aaya. Yahan samjho andar kya hota hai, aur tumhe kya karna hai.

Pending dikhe toh ye karo

  1. Dobara mat bhejo. Pehla payment baad mein success ho gaya, toh paisa do baar katega.
  2. App mein transaction kholo, UPI ref ya UTR number note karo, aur status dekho.
  3. Ruko. Dost ko bheja ho toh agle din tak, dukaan ko bheja ho toh 5 din tak paisa khud wapas aata hai.
  4. Time nikal gaya? Usi transaction pe app mein complaint karo. 30 din mein hal na ho toh RBI Ombudsman.

Andar kya hota hai

UPI app paisa nahi bhejta. Paisa bank ke paas rehta hai. App sirf ek message bhejta hai, aur NPCI ka switch wo message tumhare bank se saamne wale bank tak le jaata hai.

  • App (PhonePe, GPay)=sirf screen aur message
  • Tumhara bank paise kaatta hai=debit, sabse pehle
  • NPCI switch message aage bhejta hai=routing + hisaab
  • Saamne wala bank paise jama karta hai=credit
  • "Mil gaya" wapas aata hai=success
  • "Mil gaya" time pe nahi aaya=pending / timeout
  • Switch dobara poochta hai, jama nahi hua tha=reversal

Ek line yaad rakho: Success = debit + credit ka jawab. Pending = debit + jawab nahi.

20 minute ka task: do bank, ek switch

Ek chhota simulation jahan bank ka jawab kabhi kabhi kho jaata hai. Tumhara kaam: check-status aur reversal aisa likho ki dono ka total hamesha 500 rahe.

  1. Code upi.py naam se save karo aur python upi.py chalao. Teen chaar baar chalao.
  2. Reversal wali line (payer["bal"] += amt) comment out karke phir chalao.
  3. Optional: jab bhi SUCCESS (after check) aaye, socho tumne Pending dekh ke dobara bheja, aur switch_pay ek baar aur call karo.

Kaam kiya toh: reversal ke saath har run ke end mein ledger balanced: 500. Reversal hatao toh ek do run mein ledger leaked!. Wahi gayab 50 rupaye ke liye RBI ka T+1 rule bana hai.

upi.py 
import random

payer = {"bal": 500}                       # tumhari tapri (payer bank)
payee = {"bal": 0, "credited": set()}      # dukaandaar ki tapri (payee bank)

def payee_bank(txn, amt):
    """Beneficiary bank. Kabhi down, kabhi credit karke bhi jawab kho deta hai."""
    r = random.random()
    if r < 0.2:                            # bank down: na credit, na jawab
        return None
    payee["bal"] += amt
    payee["credited"].add(txn)
    if r < 0.4:                            # credit hua, par jawab raaste mein kho gaya
        return None
    return "OK"

def switch_pay(txn, amt):
    payer["bal"] -= amt                    # 1. pehle debit
    reply = payee_bank(txn, amt)           # 2. saamne phone lagao
    if reply == "OK":
        return "SUCCESS"
    # timeout. 3. check-status: chadhaya tha ki nahi?
    if txn in payee["credited"]:
        return "SUCCESS (after check)"
    payer["bal"] += amt                    # 4. reversal: paisa wapas
    return "REVERSED"

for i in range(10):
    status = switch_pay(f"txn{i}", 50)
    print(f"txn{i}: {status:22} payer={payer['bal']} payee={payee['bal']}")

assert payer["bal"] + payee["bal"] == 500, "ledger leaked!"
print("ledger balanced: 500")

Simplified: asli UPI mein app aur switch ke beech ek PSP bank hota hai, aur banks ka paisa baad mein net settlement mein milta hai. Par niyam wahi hai: debit hua aur credit nahi, toh reversal hona hi chahiye.

Do sawaal jo sab poochte hain

Dukaan pe pay kiya, 5 din ho gaye, paisa wapas nahi aaya?
Dobara mat bhejo. App mein us transaction pe Help ya Raise dispute karo aur bank ko UTR number do. Delay pe Rs 100 roz compensation tumhara haq hai. 30 din mein hal na ho toh cms.rbi.org.in pe RBI Ombudsman.
App ne Success dikhaya, par dukaandaar bola nahi aaya?
Success tabhi aata hai jab uske bank ne credit confirm kiya. Paisa uske account mein hai, bas uske app ka notification late ho sakta hai. Usse bank balance ya SMS check karne bolo aur UTR dikhao.
